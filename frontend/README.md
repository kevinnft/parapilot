# ParaPilot Studio 🖥️

Consumer dashboard for configuring autonomous agent session policies and monitoring real-time executions on Monad.

### Features
- **Passkey / Social Onboarding**: Powered by Dynamic / WebAuthn, granting users self-custodial smart accounts without seed phrases.
- **Visual Policy Builder**: Interactive sliders for daily spending limits, token whitelisting, and DEX router permissions.
- **Session Delegation**: One-click generation of scoped session keys for AI agent runtimes.
- **Live Activity Feed**: Real-time telemetry showing agent reasoning logs and corresponding Monad transaction hashes.
